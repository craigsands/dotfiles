# Chrome

## Dark Reader

[Dark Reader](https://chromewebstore.google.com/detail/dark-reader/eimadpbcbfnmbkopoojfekhnkhdbieeh) extension in Light mode to tint web page backgrounds toward `#fbf7f0`.

| Slider | Value |
|--------|-------|
| Mode | Light |
| Brightness | +10 |
| Contrast | off (0) |
| Sepia | +15 |
| Grayscale | off (0) |

## Site List (Not Inverted)

Sites excluded from Dark Reader (Site list > "Not invert listed"):

- `calendar.google.com`
- `google.com/maps`
